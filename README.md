# Planification FHGES S1

Outil de planification des séquences et de suivi de la matière vue pour le cours
de FHGES de 1re secondaire (référentiel du tronc commun, Fédération Wallonie-Bruxelles).

## Utilisation

La page est publiée via GitHub Pages. Elle s'ouvre dans n'importe quel navigateur :
aucun compte, aucune installation.

- Le cahier est enregistré **dans le navigateur de chaque utilisateur**. Il reste
  privé, mais ne suit pas d'un ordinateur à l'autre, et un effacement des données
  de navigation le supprime.
- L'export Excel (onglet Paramètres → Copie Excel) sert de sauvegarde : le classeur
  produit s'ouvre dans Excel sans la page, et se réimporte dans l'outil.

## Contenu

- `index.html` — l'outil complet, en un seul fichier, sans dépendance externe
  (moteur de rendu et moteur Excel inclus).
- `.nojekyll` — désactive le traitement Jekyll de GitHub Pages.
